# /memory — Query or write GBrain persistent memory

Query or update Jarvis's GBrain persistent memory store.

## Usage

```
/memory [query or content to remember]
```

## How to Execute

```bash
cd C:\Users\hasin\jarvis
.venv\Scripts\python.exe -u jarvis-cli.py --mode auto --task "Query GBrain memory for: $ARGUMENTS"
```

## Examples

- `/memory what did I work on last week`
- `/memory remember that I prefer TypeScript over JavaScript`
- `/memory show all entries about job search`
