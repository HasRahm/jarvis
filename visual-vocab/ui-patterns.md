# UI Layout & Pattern Vocabulary
> When visual_inspect describes the screen layout, match it here to understand the structure.
> Use this to orient yourself before deciding which element to click.

| Pattern Name | Visual Description | Meaning & Purpose | Interactive Elements & Actions |
|-------------|-------------------|------------------|-------------------------------|
| Top Navigation Bar / App Bar | Horizontal strip spanning the full width at the very top of the window or page. Contains app logo, page title, icons, and sometimes a search bar. Usually 40-60px tall. | Primary app navigation, branding, global actions | Icons are clickable. Logo often goes to home. Search icon opens search input. User avatar opens account menu. |
| Left Sidebar / Navigation Panel | Vertical panel along the left edge, typically 200-280px wide. Contains a list of items, sections, or icons. Narrower icon-only sidebars are 48-64px wide. | Main navigation hierarchy, page tree, channel list, file structure | Click items to navigate. Hover for tooltips. May have collapse/expand toggle. |
| Right Panel / Inspector | Vertical panel along the right edge. Contains form fields, properties, or contextual information about selected item. | Properties of selected element, inspector, details panel | Fill form fields, change values. |
| Bottom Status Bar | Thin horizontal strip at the bottom of the window (15-25px tall). Shows small text, icons, or indicators. | Status information, line/column numbers, connection status, progress | Sometimes clickable for options. Usually read-only. |
| Tab Bar / Tab Strip | Row of labeled horizontal tabs. Active tab is visually distinct: bolder, different background color, or underlined. | Switch between multiple open items or views (documents, channels, browser tabs) | Click a tab to switch to it. X on tab closes it. + adds new tab. Right-click for more options. |
| Toolbar / Action Bar | Row of icon buttons, usually below the top navigation bar or at the top of a panel. | Quick access to common actions for current context | Click icon to perform action. Hover for tooltip label. Disabled icons are grayed out. |
| Modal Dialog | A popup window that appears over the main content with a semi-transparent dark overlay behind it. Has a title bar and action buttons (OK, Cancel, Submit, etc.) | Requires user decision or input before the main UI can be used again. | Confirm/Cancel/Close buttons. Close X in top-right corner. Click outside (on overlay) may close it. Esc key usually closes. |
| Drawer / Slide-in Panel | Panel that slides in from the left or right edge, overlapping the content with a dark overlay. Similar to modal but full-height and edge-anchored. | Additional options or content without leaving current page | Has close button (X) or back arrow. Clicking overlay closes it. |
| Toast Notification / Snackbar | Small popup banner appearing from a corner (usually bottom-center, bottom-left, or top-right). Auto-dismisses after a few seconds. Different colors: green=success, red=error, yellow=warning, blue=info. | Transient feedback message (success, error, info) | May have "Dismiss" or "Undo" button. Clicking X closes it early. |
| Dropdown Menu | A floating list of options that appears below (or above) a trigger element when clicked. Items stacked vertically. Disappears when an item is selected or clicking elsewhere. | Choose one option from a list of choices | Click an item to select it. Hover items show selection state. Click outside to dismiss. Keyboard: arrow keys to navigate, Enter to select, Esc to close. |
| Context Menu | Same appearance as a dropdown menu but triggered by right-clicking instead of left-clicking. Appears at the cursor position. | Context-sensitive actions for whatever was right-clicked | Click item to execute. Esc or click elsewhere to dismiss. |
| Popover / Tooltip | Small floating box that appears when hovering over or clicking an element. Contains explanatory text or a mini-form. | Supplementary information or quick actions | Click trigger element to open. Click X or outside to close. |
| Breadcrumb Trail | Horizontal sequence of links separated by > or / arrows (e.g., Home > Projects > My Project > Page). Located near top of content area. | Shows current location in a hierarchy and provides quick navigation up | Click any breadcrumb item to navigate to that level. |
| Search Results List | A scrollable vertical list of items matching a query. Each item is a card or row with title, description, image, or metadata. | Display results from a search operation | Click item to open/select. May have filters above. Scroll to see more. |
| Card Grid | A grid of equal-size rectangular cards. Each card has a thumbnail/preview image and a title/description below. Rows and columns of content. | Visual browsing of items (designs, products, posts) | Click card to open the item. Hover may reveal action buttons. |
| List View | Vertical list of items as rows. Each row shows text, metadata, and action buttons. More dense than card grid. | Browse items with more text detail visible | Click row to open. Row hover reveals action icons. |
| Pagination | Row of page number buttons or "Previous" / "Next" text buttons at the bottom of a list or grid. Usually: < 1 2 3 ... 10 > | Navigate through multiple pages of results | Click number to jump to page. Click < > arrows for previous/next. |
| Floating Action Button (FAB) | A large prominent circular button floating above the content, usually in the bottom-right corner. Often has a + or specific icon. Has a shadow/elevation. | Primary creation or important action for this screen | Click to trigger the primary action (create, add, compose). |
| Accordion / Collapsible Section | A section with a clickable header row that shows/hides its content. Usually has a + or > arrow icon that changes to – or v when expanded. | Collapsible content sections to reduce visual clutter | Click header to toggle expand/collapse. |
| Segmented Control / Toggle Group | A row of options displayed as connected buttons, where one is selected at a time (highlighted). Looks like tabs but usually for toggling views, not navigating. | Mutually exclusive view/filter toggle | Click an option to select it. Selected option has different background. |
| Form / Input Form | A structured area with labeled input fields (text inputs, dropdowns, checkboxes, radio buttons) stacked vertically. Usually ends with Submit/Save button. | Data input for creating or editing a record | Click field to focus, type value. Submit button saves. Required fields may have asterisk (*). |
| Empty State | Large centered icon with a title and description text in the middle of the content area. Often includes a call-to-action (CTA) button. Text like "No results", "Nothing here yet", "Get started". | No content to show in this section | CTA button creates or adds first item. May have illustration. |
| Loading Spinner / Skeleton Screen | A rotating circle (spinner) OR grayed-out placeholder shapes where content will appear (skeleton). | Content is loading, wait for it. Do not interact yet. | Not clickable. Wait until spinner disappears before taking action. |
| Progress Bar | A horizontal bar partially filled with color (e.g., 70% filled). May have a percentage label. Sometimes animated with a striped fill. | Shows completion percentage of a task/upload/process | Usually informational. May have cancel button nearby. |
| Stepper / Wizard | A sequence of labeled steps shown at top (Step 1: Info → Step 2: Review → Step 3: Confirm). Current step highlighted. | Multi-step process that must be completed in order | Complete current step then click Next. May navigate back via Back. |
| Split Pane / Divider | The window is divided into two or more sections by a draggable divider bar (vertical or horizontal line between panels). | Side-by-side comparison, code + preview, navigation + content | Drag divider to resize panels. May have collapse buttons at edges. |
| Canvas / Drawing Surface | A large, usually white or dark area that can be panned (click and drag to move) and zoomed (scroll wheel). Shows design, diagram, or document content. May have rulers at edges. | Main editing surface for design, diagramming, or document tools | Drag to pan. Scroll to zoom. Click elements on canvas to select. |
| Ribbon (Office-style) | Wide toolbar with large icons grouped into sections/tabs at the top of the window. Each section has a label at bottom. Multiple tabs switch the ribbon content. | Comprehensive command surface for complex applications (Word, Excel) | Click tab to switch ribbon section. Click icon to perform action. |
| Menu Bar | Horizontal bar of text menu names: File, Edit, View, Help, etc. Below the window title bar. | Traditional application menu navigation | Click menu name to open dropdown of commands. Keyboard: Alt key shows underlined shortcuts. |
| Notification Badge | Small red/orange circle or dot overlay on an icon, often containing a number (e.g., "3"). | Indicates unread notifications, messages, or alerts | Check the number. Click the icon with the badge to view notifications. |
| Tooltip | Small dark popup box with text that appears on hover near the cursor. | Explains what a button or icon does | Not interactive. Just informational. Shows on hover, disappears when cursor moves. |
| Highlight / Selected State | An item with visually distinct background (blue highlight, border, or checkmark) compared to others in the same list or grid. | Indicates currently selected item | Click different item to change selection. Multi-select: Ctrl+Click or Shift+Click. |
| Disabled State | An element (button, field, link) that appears grayed out or with reduced opacity. Cursor shows "not-allowed" when hovering. | Element is not currently interactive or available | Cannot click. May need to complete a prerequisite action first. |
| Scrollbar | Thin bar along the right side (vertical scroll) or bottom (horizontal scroll) of a content area. Has a thumb that indicates position. | Indicates there is more content beyond the visible area | Drag thumb to scroll. Click track above/below thumb to jump. Scroll wheel also works. |
| Sidebar Navigation (Vertical tabs) | Left sidebar where each item is a navigation destination, visually like vertical tabs. Active item has different background or left border accent. | Switch between major sections of an app | Click item to navigate. Active item highlighted. |
| Inline Edit | Clicking on a text value causes it to transform into an input field in place, without opening a dialog. | Edit value directly without a modal | Click value to start editing, type new value, press Enter to confirm or Esc to cancel. |
| Drag and Drop Zone | An area with dashed border or cloud-with-arrow icon and text like "Drop files here" or "Drag to upload". | Accepts dropped files or items | Drag a file from desktop or another location and drop here. Or click to browse files. |
| Tree View | Hierarchical list where items can be expanded/collapsed. Parent items have > triangle or + before them. Child items are indented. | File/folder hierarchy, project tree, component tree | Click > to expand. Click item to select. Right-click for context menu. |
| Color Picker | A square or circle gradient field + a hue slider + hex/RGB input fields. Often appears in a popover. | Select a specific color value | Click in gradient to pick tone. Drag hue slider for base color. Type hex value directly. |
| Date Picker Calendar | A month calendar grid showing days. Navigation arrows for previous/next month. Selected date highlighted. | Select a specific date | Click a day to select it. Use < > arrows to change month. |
| Time Picker | Digital clock display with scrollable or clickable hour/minute segments. | Select a specific time | Click AM/PM toggle. Scroll or click hour/minute values. |
| Autocomplete / Suggestion Dropdown | Text input field with a dropdown appearing below showing suggestions as you type. Items update with each keystroke. | Quickly find and select from a large list | Keep typing to filter. Click suggestion or press arrow keys + Enter to select. |
| Combobox / Select Input | A field showing the selected value with a downward chevron (v) arrow. Clicking opens a dropdown list. | Choose one value from a predefined list | Click the field to open dropdown. Click desired option. |
| Checkbox | A small square box, empty or with a checkmark inside. Label text beside it. | Toggle a boolean on/off option | Click checkbox or label to toggle. Checked = enabled. |
| Radio Button | Small circle, empty or with filled center dot. Part of a group where only one can be selected. Label beside it. | Choose exactly one option from a group | Click circle or label to select. Selecting one deselects others. |
| Toggle Switch | Pill-shaped track with a circular thumb. Thumb on left = off. Thumb on right = on. Different background colors for on/off states. | Toggle a feature or setting on or off | Click the toggle to switch states. |
| Slider | A horizontal track with a draggable circular thumb. May have min/max labels at ends. | Set a numeric value within a range (volume, opacity, price) | Drag thumb left/right. Click track to jump. |
| Range Slider | Two thumbs on a track, defining a minimum and maximum range. | Define a value range (e.g., price range filter) | Drag each thumb independently. |
| Chip / Tag | Small rounded rectangle containing a label, sometimes with an X to remove. | Category filter, selected item, label | Click chip to select/deselect filter. Click X to remove. |
| Avatar / Profile Picture | A circular or rounded-square image showing a person's photo, or initials on a colored background if no photo. | Identifies a user | Click to open profile or account menu. |
| Data Table | Grid with rows and columns of data. Header row at top with column names. May have sorting arrows on column headers. Rows may be selectable. | Structured data display | Click column header to sort. Click row to select. Right-click for context. |
| Kanban Board | Groups of vertical columns, each with stacked card items. Column headers indicate status (To Do, In Progress, Done). | Visual workflow management | Drag cards between columns. Click card to open detail. Click + to add card. |
| Timeline View | Horizontal axis represents time. Tasks/events shown as horizontal bars at various positions. | Scheduling, project planning, Gantt chart | Click event bar to view details. Drag to reschedule. |
| Sidebar Chat Thread | Vertical panel showing a list of messages in chronological order. Input box at bottom. | Conversation or chat history | Scroll up for history. Click input at bottom and type to respond. |
