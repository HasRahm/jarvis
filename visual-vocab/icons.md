# UI Icon Vocabulary
> Reference for Jarvis to interpret icons seen in visual_inspect screenshots.
> When visual_inspect describes a shape, match it here to understand its function.
> Use this vocabulary when forming visual_click descriptions or interpreting screenshots.

| Icon Name | Visual Shape Description | Meaning / Function | Typical Location | Action |
|-----------|-------------------------|-------------------|-----------------|--------|
| Search | Magnifying glass: circle with a diagonal handle at bottom-right | Open search input, find/lookup | Top bar, sidebar top, top-right | Click to activate search input, then type |
| Settings / Preferences | Gear or cog wheel with teeth around circumference | Open settings, preferences, configuration panel | Top-right, sidebar bottom, menu | Click to open settings |
| Close / Dismiss | X mark, two diagonal lines crossing | Close window, dismiss modal, cancel | Top-right corner of window or modal | Click to close |
| Menu / Navigation toggle | Three horizontal parallel lines (hamburger) | Open navigation menu or sidebar | Top-left corner | Click to expand navigation |
| Add / Create | Plus sign (+), sometimes in a circle or floating button | Create new item, add entry | Toolbar, floating action button (FAB) | Click to create |
| Delete / Remove | Trash can outline | Delete selected item permanently | Toolbar (after selection), list row | Click, confirm dialog may appear |
| Save | Floppy disk outline (legacy) or cloud with up-arrow | Save current state to disk or cloud | Toolbar, title bar area | Click to save |
| Back | Left-pointing arrow (←) | Go to previous page/view | Top-left, navigation bar | Click to navigate back |
| Forward | Right-pointing arrow (→) | Go to next page/view | Top-left beside Back | Click to navigate forward |
| Home | House silhouette outline | Return to main/home screen | Navigation bar, sidebar top | Click to go home |
| Notifications | Bell outline | View notifications and alerts | Top-right area, near profile icon | Click to open notifications panel |
| User / Profile | Person silhouette or circle with initials/photo | Account settings, profile menu | Top-right corner | Click to open account menu |
| Share | Arrow pointing up from a box (iOS style) OR branching nodes | Share content or generate link | Toolbar, context menu | Click to open share options |
| Download | Arrow pointing down into a box or tray | Download file to local storage | Toolbar, file action buttons | Click to download |
| Upload | Arrow pointing up into a box or cloud | Upload file from local storage | Toolbar, file action buttons | Click to open file picker |
| Filter | Funnel or triangle narrowing downward | Filter list or search results | Toolbar, beside search bar | Click to open filter panel |
| Sort | Two arrows pointing in opposite directions (up-down) or A-Z label | Sort list order | Toolbar, column headers | Click to toggle sort order |
| Expand / Maximize | Square with arrows pointing outward at all four corners | Expand panel or maximize window | Panel header, card top-right | Click to expand |
| Collapse / Minimize | Square with arrows pointing inward toward center | Collapse panel to smaller size | Panel header when expanded | Click to collapse |
| Refresh / Reload | Circular arrow (rotating clockwise) | Refresh data or reload page | Toolbar, browser address bar area | Click to reload |
| Copy | Two overlapping rectangles (front slightly offset) | Copy text or item to clipboard | Context menu, toolbar | Click to copy |
| Paste | Clipboard with a small arrow or content | Paste from clipboard | Context menu, toolbar | Click to paste |
| Cut | Scissors icon | Cut selected content | Context menu, toolbar | Click to cut |
| Edit / Pencil | Pencil or pen icon, often angled 45 degrees | Edit current item or enter edit mode | List row, toolbar | Click to enter edit mode |
| Link / Hyperlink | Chain links (two interlocked oval rings) | Copy or insert a hyperlink | Toolbar, context menu | Click to get or set link |
| Attach / Paperclip | Paperclip shape | Attach a file to message or record | Message/email input, toolbar | Click to open file attachment picker |
| Star / Favorite | Five-pointed star outline or filled | Mark as favorite or starred | List row, toolbar, card | Click to toggle favorite state |
| Bookmark | Rectangle with V-cut or notch at bottom | Save for later, bookmark page | Browser toolbar, content cards | Click to bookmark |
| Tag / Label | Price tag or label shape with hole | Add category or label | Item action menu | Click to tag or categorize |
| Eye / Visibility | Eye outline (open) or eye with line through it (hidden) | Show or hide element, toggle visibility | Password fields, layer panels | Click to toggle visibility |
| Lock / Security | Padlock icon (closed = locked, open = unlocked) | Security setting, password protected | Browser address bar (HTTPS), access controls | Indicates secure or locked state |
| Unlock | Open padlock icon | Unlocked, editable, accessible | Next to locked items | Click to lock or indicates unlocked |
| Info | Lowercase "i" in a circle | Help information, tooltip, description | Near form fields, card footers | Click for more information |
| Warning / Alert | Exclamation mark (!) inside a triangle | Warning or important alert requiring attention | Status indicators, notification banners | Read the warning, may require action |
| Error | X inside a red circle OR red exclamation mark | Error state, action failed | Status indicators, form validation | Review error message and fix |
| Success / Check | Checkmark (tick) inside a green circle | Success, completed, confirmed | Status indicators, list items, buttons | Indicates success state |
| Drag handle | Six dots in 2x3 grid OR three short horizontal lines | Drag to reorder items in list | Left edge of list items, card handles | Click and drag to reorder |
| Overflow / More options | Three dots horizontally (ellipsis ...) or vertically (⋮) | More options or actions menu | List row right end, card corners | Click to open dropdown of more options |
| Grid view | 2x2 or 3x3 square grid pattern | Switch to grid or tile layout | View toggle buttons, top-right area | Click to switch to grid view |
| List view | Horizontal lines of varying lengths (list symbol) | Switch to list layout | View toggle buttons, beside grid icon | Click to switch to list view |
| Zoom in | Magnifying glass with plus (+) sign inside | Zoom in, increase scale or size | Canvas toolbar, image viewer | Click to zoom in |
| Zoom out | Magnifying glass with minus (-) sign inside | Zoom out, decrease scale or size | Canvas toolbar, image viewer | Click to zoom out |
| Play | Right-pointing filled triangle (▶) | Play media, start process, run | Media player controls, video thumbnails | Click to play |
| Pause | Two vertical parallel bars (‖) | Pause media, suspend process | Media player controls (when playing) | Click to pause |
| Stop | Filled square (■) | Stop media or running process | Media controls, process manager | Click to stop completely |
| Skip forward | Triangle pointing right with vertical bar (⏭) | Skip to next track or forward | Media controls | Click to skip |
| Skip back | Vertical bar with triangle pointing left (⏮) | Skip to previous track | Media controls | Click to go back |
| Rewind | Two triangles pointing left (◀◀) | Rewind or fast reverse | Media controls | Click to rewind |
| Fast forward | Two triangles pointing right (▶▶) | Fast forward | Media controls | Click to fast forward |
| Volume | Speaker outline, with waves for louder, X for muted | Audio volume control | Media players, system tray | Click to open volume slider or toggle mute |
| Mute | Speaker with X mark | Muted state | Media controls | Click to unmute |
| Calendar | Grid with top border bar (monthly calendar icon) | Date picker or calendar view | Date input fields, scheduling apps | Click to open date picker |
| Clock / Time | Circle with clock hands indicating time | Time value, schedule, timestamp | Time input fields, timestamps | Indicates time-related function |
| Location / Map pin | Teardrop or pin shape pointing downward | Location, geotag, address | Location input fields, map apps | Click to set or view location |
| Phone | Telephone handset outline | Phone call or phone number | Contact information, communication apps | Click to initiate call |
| Email / Mail | Envelope outline | Email address or compose email | Contact info, communication buttons | Click to compose or open email |
| Chat / Message | Speech bubble outline (rounded rectangle with tail) | Chat, message, comment | Communication tools, comment sections | Click to open chat or add comment |
| Video call | Video camera outline | Video call or video feature | Communication apps, meeting tools | Click to start video call |
| Code | Angle brackets (< >) or curly braces ({ }) | Code view, developer settings, embed | Code editors, developer settings | Click to toggle code view |
| Terminal / Command | Greater-than symbol with underscore (>_) or $ prompt | Command line or terminal | Developer tools, system utilities | Click to open terminal |
| AI / Sparkle | Four-pointed star, wand with sparkles, or star cluster | AI-powered feature, magic/smart action | Beside text inputs, toolbar | Click to trigger AI-assisted action |
| Layers | Multiple overlapping rectangles (stacked) | Layer management, Z-order | Design tools, image editors | Click to open layers panel |
| Palette / Color | Paint palette outline or color circle | Color picker, theme settings | Design tools, appearance settings | Click to open color picker |
| Crop | Two overlapping L-shapes or right-angle brackets | Crop image or selection | Image editors, cropping tools | Click to enter crop mode |
| Rotate | Circular arrow around a point or shape | Rotate object or screen | Image tools, display settings | Click to rotate |
| Undo | Curved arrow pointing left (counterclockwise) | Undo last action | Toolbar, Edit menu | Click to undo (or Ctrl+Z) |
| Redo | Curved arrow pointing right (clockwise) | Redo last undone action | Toolbar, Edit menu | Click to redo (or Ctrl+Y) |
| Print | Printer outline with paper | Print current document | File menu, toolbar | Click to print |
| Export | Arrow pointing out of a box or document | Export/save to file format | File menu, toolbar | Click to export |
| Import | Arrow pointing into a box or document | Import file or data | File menu, toolbar | Click to import |
| Sync / Cloud sync | Two circular arrows OR cloud with arrows | Sync data with cloud or server | Status bar, settings | Click to force sync or indicates syncing |
| Cloud | Cloud outline | Cloud storage, online resource | Storage indicators, save options | Click to access cloud storage |
| Folder | Folder tab shape | Open folder, file organization | File browsers, breadcrumbs | Click to open folder |
| File / Document | Rectangle with top-right corner folded | Single document or file | File lists, attachments | Click to open file |
| Image | Rectangle with mountain/sun landscape inside | Image file, photo, picture | Media files, galleries | Click to view image |
| Video file | Film strip or clapperboard shape | Video file | Media files | Click to play video |
| Table | Grid of cells with borders | Table or spreadsheet view | Data views, database tools | Click to open table view |
| Chart / Graph | Bar chart or line chart | Data visualization, analytics | Dashboard widgets, reports | Click to view chart |
| Dashboard | Grid of small widgets or tiles | Overview dashboard | Navigation, home views | Click to go to dashboard |
| Help / Question | Question mark (?) in a circle | Help, FAQ, documentation | Top-right, form fields, settings | Click for help |
| External link | Small arrow pointing up-right with box | Opens in new tab or external site | Link text, buttons | Click to open in new window |
| Collapse left sidebar | Arrow pointing left with vertical bar | Collapse/hide left sidebar | Left sidebar edge | Click to hide sidebar |
| Expand left sidebar | Arrow pointing right with vertical bar | Expand/show left sidebar | Left edge when collapsed | Click to show sidebar |
| Network / WiFi | Arcing waves like radio signal | Network status, wireless connection | Status bars, network settings | Indicates connection strength |
| Bluetooth | B-like shape with angles | Bluetooth connectivity | System settings, device pairing | Click to manage Bluetooth |
| Battery | Rectangle with small bump on right | Battery level or power status | Laptop taskbar, mobile status bars | Hover for percentage |
| Microphone | Upright capsule shape on a stand | Microphone, audio input, voice | Audio settings, recording, voice input | Click to toggle microphone |
| Camera / Photo | Camera body outline | Take photo, access camera | Camera apps, profile picture | Click to capture or access photos |
| Screenshot | Camera with dotted border or screen outline | Take screenshot | Utility menus, screenshot tools | Click to capture screenshot |
| Text / Font | Letter A with sizing marks | Text formatting, font settings | Text editors, design tools | Click to open text options |
| Bold | Bold letter B | Bold text formatting | Text editor toolbar | Click to toggle bold |
| Italic | Italic letter I | Italic text formatting | Text editor toolbar | Click to toggle italic |
| Underline | Letter U with underline | Underline text formatting | Text editor toolbar | Click to toggle underline |
| Align left | Lines aligned to left edge | Left-align text | Text editor toolbar | Click to left-align |
| Align center | Lines centered | Center-align text | Text editor toolbar | Click to center |
| Align right | Lines aligned to right edge | Right-align text | Text editor toolbar | Click to right-align |
| Bullet list | Small circle with horizontal line beside it (repeated) | Unordered list | Text editor toolbar | Click to create bullet list |
| Numbered list | Number with horizontal line beside it (repeated) | Ordered/numbered list | Text editor toolbar | Click to create numbered list |
| Indent | Arrow pointing right with horizontal lines | Indent text or increase level | Text editor, outline tools | Click to indent |
| Outdent | Arrow pointing left with horizontal lines | Outdent text or decrease level | Text editor, outline tools | Click to outdent |
| Fullscreen | Four corner arrows pointing outward | Enter fullscreen mode | Video players, apps | Click to go fullscreen |
| Exit fullscreen | Four corner arrows pointing inward | Exit fullscreen mode | Fullscreen apps | Click to exit fullscreen / press Esc |
| Pin | Thumbtack or pin icon | Pin item, keep visible, mark important | Notes, cards, tabs | Click to pin |
| Move / Pan | Four-directional arrow or hand cursor | Move or pan view/object | Canvas tools, drag handles | Click and drag to move |
| Resize | Double-headed arrow diagonal | Resize element | Element corners and edges | Click and drag to resize |
| Select | Arrow cursor icon | Selection tool | Tool palettes (design apps) | Click to switch to select tool |
| Draw / Pen | Pen nib or pencil | Drawing or annotation tool | Tool palettes | Click to use drawing tool |
| Eraser | Rectangle with angled bottom (eraser shape) | Erase or clear | Drawing tools | Click to use eraser |
| Eyedropper | Medical dropper / color picker tool | Sample color from screen | Color picker, design tools | Click then click color to sample |
| Ruler | Ruler with measurement marks | Show/hide rulers or measure | Design tools, layout | Click to toggle ruler |
| Grid (layout) | Regular dot grid or line grid | Show/hide grid overlay | Design tools, canvas | Click to toggle grid |
| Snapping | Magnet icon | Toggle snapping to grid/guides | Design tools | Click to toggle snap |
| Comment | Speech bubble with pencil or lines | Add comment, annotation | Design tools, documents, code | Click to add comment |
| Reaction / Emoji | Smiley face outline | Add emoji reaction | Chat, messaging, comments | Click to open emoji picker |
| Flag | Flag waving on pole | Mark, flag for review, country indicator | Project management, localization | Click to flag item |
| Archive | Box with down-arrow | Archive or store item | Email, project tools | Click to archive |
| Spam | Prohibition circle (no-sign) over envelope | Mark as spam, block | Email, moderation | Click to mark as spam |
| Send | Paper airplane outline | Send message or submit | Message inputs, forms | Click to send |
| Reply | Arrow curving back to envelope or message | Reply to message | Email, chat | Click to reply |
| Forward message | Arrow pointing forward from envelope | Forward message to someone | Email, chat | Click to forward |
