# WARP.md - Warp Custom Commands & Blocks

This document lists the custom blocks, rendering wrappers, and slash commands configured for the Warp terminal integration.

## Custom Blocks
* **Jarvis Visual Block**: Monospace terminal panel that renders visual screen states, containing:
  - Focused application title and process attributes.
  - OCR aggregated text summary generated by the local Gemma4 model.
  - Active UI interaction nodes with layout positions.
  - Vectorized ASCII halftone visual density imprint (32x32 character grid).

## Registered Slash Commands

### 🟢 `/screen`
* **Purpose**: built-in Jarvis diagnostic command to inspect screen state.
* **Execution**: `.venv\Scripts\python.exe -u jarvis-cli.py --screen`
* **Output Format**: Single Warp block wrapping visual status sections and high-speed NumPy density matrices.
